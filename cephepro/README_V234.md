# CephePro V234

Seçili dilde otomatik yapay zekâ çevirisi: ayrı başlatma düğmesi kaldırıldı. Desteklenen masaüstü tarayıcıda dil seçimi veya ilk sayfa etkileşimi dil paketini başlatır. Sonradan açılan ekranlar ve açıklamalar otomatik işlenir. Model sayı/Poz No değiştirirse önce korunmuş değerlerle, ardından yalnız açıklama parçalarıyla yeniden çeviri denenir. Ücretli çeviri API isteği yoktur. Modeli desteklemeyen cihazlarda veya model hatasında tam çeviri garanti edilmez; açıklamalar silinmeden korunur.

Kişisel Düzenim kullanıcı hesabına özel olarak buluta kaydedilir. Aynı hesapla diğer cihazda yüklenir. Eski yerel kayıtlar, bulut kaydı yoksa eski cihaz ilk açıldığında aktarılır. İki cihazın eşzamanlı kaydı sürüm kontrolüyle korunur. Eski düzenin bulunduğu cihazda Kişisel Düzenimi Kaydet ile bulut kaydını doğrulayabilirsiniz.

Uzun buton yazıları için satır kaydırma, esnek yükseklik ve panel genişliği sınırları eklendi. Görsel tarayıcı testi ortamın izin kısıtı nedeniyle tamamlanamadı.
